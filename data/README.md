# 收集資料說明

此資料夾包含從 Emogo App 實際收集的情感資料。

## 📊 資料檔案

- **sentiment_records.json** - 情感評估記錄（PAD 模型）
- **vlog_records.json** - 1秒影片記錄
- **gps_records.json** - GPS 座標記錄
- **emogo_exported_data.json** - 完整匯出資料

## 📅 收集統計

- **記錄數量**: 5 筆完整記錄
- **時間跨度**: 約 19 小時
- **資料類型**: 結構化主動資料、非結構化主動資料、結構化被動資料

## �� 資料格式

每筆記錄包含三個同步收集的資料類型：

1. **情感評估** - PAD 三維度量表（1-9分）+ 文字備註
2. **1秒影片** - 影片檔案路徑 + 錄影時長
3. **GPS座標** - 緯度、經度、精確度
