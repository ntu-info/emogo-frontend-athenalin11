# Data 資料夾說明

此資料夾用於儲存從應用程式匯出的資料，作為作業繳交的一部分。

## 📋 要求

根據作業規定，需要：
- **至少 3 筆記錄**（每種資料類型）
- **時間跨度 > 12 小時**（最後一筆 - 第一筆）

## 📊 資料類型

### 1. 情緒問卷資料 (Sentiment Records)
- 結構化主動資料
- 包含：愉悅度、激動度、主導度（1-9 量表）
- 時間戳記

### 2. 影片記錄 (Vlog Records)
- 非結構化主動資料
- 包含：影片 URI、錄影時長
- 時間戳記

### 3. GPS 位置記錄 (GPS Records)
- 結構化被動資料
- 包含：緯度、經度、精確度
- 時間戳記

## 📤 如何匯出資料

1. 開啟應用程式
2. 進入「設定」頁面
3. 點擊「匯出所有資料」
4. 選擇儲存位置
5. 將匯出的 JSON 檔案複製到此資料夾

## 📝 範例資料格式

```json
{
  "exportDate": "2025-11-22T10:30:00.000Z",
  "sentimentRecords": [
    {
      "id": 1,
      "timestamp": "2025-11-22T08:00:00.000Z",
      "valence": 7,
      "arousal": 5,
      "dominance": 6,
      "notes": "早上心情不錯"
    }
  ],
  "vlogRecords": [
    {
      "id": 1,
      "timestamp": "2025-11-22T08:00:30.000Z",
      "video_uri": "file:///path/to/video.mp4",
      "duration": 1
    }
  ],
  "gpsRecords": [
    {
      "id": 1,
      "timestamp": "2025-11-22T08:00:45.000Z",
      "latitude": 25.0330,
      "longitude": 121.5654,
      "accuracy": 10.5
    }
  ],
  "stats": {
    "totalSentiment": 3,
    "totalVlogs": 3,
    "totalGPS": 3
  }
}
```

## ✅ 完成清單

使用應用程式收集資料後：
- [ ] 第一次記錄（例如：早上 8:00）
- [ ] 第二次記錄（例如：下午 3:00）
- [ ] 第三次記錄（例如：晚上 8:00，隔天）
- [ ] 確認時間跨度 > 12 小時
- [ ] 匯出資料到此資料夾
- [ ] 檢查資料完整性

## 📌 注意事項

- 確保每種資料類型都有至少 3 筆記錄
- 記錄時間要分散（不要在短時間內連續記錄）
- 最理想的情況是跨越 1-2 天收集資料
- 匯出的 JSON 檔案要保留在此資料夾中

---

**提示：** 在測試階段可以手動調整系統時間來模擬不同時段的記錄，但正式繳交時建議使用真實的時間記錄。
